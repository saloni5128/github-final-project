# Simple Interest Calculator

A simple application and script designed to calculate the simple interest based on user inputs for principal, annual rate of interest, and time period.

## About the Project
This project is part of a hands-on lab practicing version control using Git and GitHub. It includes a Bash script (`simple-interest.sh`) that computes financial interest quickly and accurately.

## Formula
Simple Interest is calculated using the standard formula:
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount (initial investment or loan)
* **R** = Annual rate of interest (percentage)
* **T** = Time period (in years)
